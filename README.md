PolyDamE calculates damage energies from PKA energies for arbitrary polyatomic materials using deterministic methods.

Detailed descriptions of the methods and representative results can be found in our paper published in _Journal of Nuclear Materials_ 631 (2026) 156797, doi: 10.1016/j.jnucmat.2026.156797

Users are encouraged to read and cite this paper when using this repository.

Results are automatically saved in the file named {material_name}.dat, where {material_name} can be any user-defined string.
All energies are given in eV, with E_PKA in the first column.

Some comments in the source files will be updated soon.
